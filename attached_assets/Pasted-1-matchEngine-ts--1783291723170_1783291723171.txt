1. Матч-движок (matchEngine.ts)
Работает:

Расчёт силы команды — атрибуты × физические коэффициенты (усталость, форма, острота, моральный дух)
Симуляция счёта — модель «попыток»: 8–14 ударов у каждой стороны, вероятность гола от 4% до 55%
Таймлайн событий — голы + 1–3 жёлтых карточки
Последствия для игроков — усталость, форма, моральный дух, травмы с разными типами и временем восстановления
Заглушки / дыры:

❌ Позиционирование — «лучшие 11» выбираются по среднему атрибуту без учёта амплуа. Может выйти 11 нападающих
❌ Тактики и расстановки — не существует
❌ Замены — не реализованы
❌ Рейтинг матча — 5 + Math.random() * 4, не привязан к реальному вкладу
❌ Соперник — просто одно число силы + хардкодный список имён ("Вильяррос", "Мартинель")
❌ Вратарская логика — отсутствует, GK ничем не отличается от защитника
2. Tick-система (tickEngine.ts)
Работает:

Продвижение даты на 7 дней за тик
Запуск симуляции всех матчей в окне недели
Восстановление усталости (formула: 7 − 1.5×матчей дней отдыха)
Заживление травм (декремент weeksLeft)
Дрейф морали к базовому значению 65
Чего нет:

❌ Автоматический тик — запускается только вручную по кнопке игрока, реального cron-а нет
❌ Возраст — не обрабатывается
❌ Окончание контрактов — логика не существует
❌ Влияние медперсонала на скорость восстановления — атрибут есть, не используется
3. INBOX
Работает:

Тип InboxMessage определён
Несколько сообщений создаются (итоги матчей, базовые отчёты)
UI для чтения сообщений есть
Чего нет:

❌ Событийная подписка — inbox не слушает матч-движок или тик. Сообщения добавляются вручную в нескольких местах
❌ Травма → сообщение, конец контракта → сообщение, предложение о трансфере → сообщение — не реализовано
❌ Тексты шаблонные, без реального контекста матча
4. Трансферный AI
Работает:

UI рынка (MarketTab.tsx) — фильтры, отображение игроков
Генерация игроков/персонала по шаблонам
Списание бюджета при покупке
Не существует вообще:

❌ AI-клубы — нет сущностей, нет бюджетов, нет логики покупки/продажи
❌ Переговоры — покупка мгновенная
❌ Скаутинг — атрибут hidden.scouted объявлен, нигде не используется
❌ Динамическая стоимость — цена фиксируется при генерации, не меняется
5. Календарь/Расписание (scheduleEngine.ts)
Работает:

Генерация полного сезона (лига + кубки + еврокубки)
Защита от дублирования дат
Привязка к стране (название кубка: FA Cup, Coppa Italia…)
Заглушки:

❌ Не round-robin — соперники назначаются по модулю (round % rivals.length), один и тот же соперник может встретиться дважды, другой — ни разу
❌ AI vs AI матчи — не симулируются вообще, турнирная таблица не отражает реальность
❌ Даты еврокубков — хардкодные строки для сезона 2025/2026, не масштабируются
Итоговая таблица
Система	Статус
Матч-движок (базовая механика)	✅ Работает, но без позиций/тактик
Тик (ручной)	✅ Работает
Тик (автоматический cron)	❌ Отсутствует
Inbox (базовый)	⚠️ Есть структура, не событийный
Трансферный рынок (игрок→покупка)	✅ Работает
Трансферный AI (клуб vs клуб)	❌ Не существует
Расписание (генерация)	✅ Работает
Расписание (round-robin)	❌ Заглушка (модуль)
Главный вывод: фундамент есть — матч считает результаты, тик продвигает время, рынок работает. Но вся система работает только с точки зрения одного игрока. AI-мира (клубов, соперников с реальными составами, трансферного рынка между клубами) не существует. Это и есть главный архитектурный пробел.
